phishtrain

Security awareness·Full-stack web app

Paste a suspicious email — Claude tears it apart. Assigns a 0–100 phishing score, flags red flags with direct quotes from the message, and generates quiz questions tailored to your own analysis history. A full-stack consumer-facing app that makes phishing literacy a habit, not a corporate training slog.

  • End-to-end full stack. FastAPI backend, vanilla-JS tabbed SPA (Analyze / History / Quiz), SQLite persistence, static file serving — zero build step. One pip install and it runs.
  • Consumer-grade AI UX. Animated score bar, verdict badges (phishing / suspicious / legitimate), reply-to mismatches auto-highlighted, extracted-quote evidence per red flag, gamified quiz that reinforces lessons from your actual inbox.
  • Defense-in-depth against prompt injection. A deterministic email parser extracts headers / links / reply-to mismatches server-side before the LLM sees anything — the model gets pre-extracted context, not the email verbatim.
  • Structured outputs over chat. messages.parse() with Pydantic schemas (PhishingAnalysis, QuizQuestion). Every response is validated before it reaches the UI.

threat-radar

Threat intelligence·MCP server + CLI

An MCP server that any agentic client (Claude Desktop, Cursor, or your own agent) can plug into. Claude reads unstructured threat advisories — CISA alerts, vendor blogs, CERT notices — extracts structured intel (CVEs, IOCs, affected products) via messages.parse(), and correlates it against an IT/OT asset inventory.

  • MCP-native integration. Built on FastMCP with stdio transport, exposing list_inventory, ingest_advisory, and assess_exposure as first-class MCP tools. Any modern agent host can consume it.
  • Structured outputs over free-form prose. Uses client.messages.parse() with Pydantic schemas instead of parsing markdown. The LLM is a validated extractor, not a chatty assistant.
  • Clean separation of concerns. LLM does unstructured-to-structured translation; a pure-function correlator handles asset-matching and crown-jewel / OT-aware recommendations. 5 deterministic unit tests, no LLM mocking.

exposure-radar

Exposure management·FastAPI + HTML dashboard

A FastAPI service where a Claude agent investigates a mock enterprise inventory, correlates installed software against a CVE feed, and returns a prioritized exposure report a SOC manager can act on this morning.

  • Hybrid agent architecture. A pure-function scorer blends CVSS × asset criticality × internet-exposure × CISA KEV multipliers deterministically; the LLM owns the triage narrative and OT-aware recommendations.
  • IT/OT depth. Crown-jewel SCADA HMIs, Modbus PLC stacks, OT-specific patching constraints. Sample inventory surfaces Log4Shell on a Windows historian and EternalBlue on a Windows 7 SCADA HMI.
  • Full product surface. Structured REST endpoints (POST /scan, GET /correlate, /assets, /cves), a zero-dependency HTML dashboard for demos, a uvicorn CLI entry point, and 7 unit tests on the scoring logic.

my-app

Detection & response·CLI agent

A command-line tool that drops a Claude agent into a workspace of logs and configs, discovers artifacts, runs heuristic scanners, correlates findings across files, and produces a markdown incident report.

  • Full agent loop. The agent picks its own tools — lists the workspace, reads raw files, runs SSH brute-force and permissive-firewall detectors, then decides when it has enough evidence to stop and write the report.
  • Security engineering rigor. Pure-function detectors live in their own module with deterministic unit tests. Every file access is sandboxed to a workspace root to block path traversal.
  • Modern Anthropic SDK patterns. @beta_tool decorated tool functions, a prompt-cached system prompt, adaptive thinking on Opus 4.7.
